# ⚛️ React Labs

Repositorio dedicado al aprendizaje y práctica de **React**, mediante el desarrollo de pequeñas aplicaciones y ejercicios enfocados en fortalecer mis habilidades de desarrollo frontend.

Los proyectos están basados principalmente en el curso *React y TypeScript — La Guía Completa* de Udemy, complementados con experimentos y mejoras personales.

## 🎯 Objetivos

- Fortalecer los fundamentos de React.
- Comprender el funcionamiento de componentes, props y hooks.
- Practicar el manejo del estado y los eventos.
- Consumir APIs externas.
- Implementar formularios y validaciones.
- Aplicar TypeScript en aplicaciones React.
- Explorar herramientas modernas del ecosistema React.
- Mejorar la organización, mantenibilidad y calidad del código.

## 🛠️ Tecnologías

Las tecnologías utilizadas pueden variar según el proyecto.

- React
- JavaScript
- TypeScript
- Vite
- HTML5 y CSS3

Otras herramientas y librerías se documentarán a medida que sean utilizadas.

## 💻 Ejecutar un proyecto

Cada aplicación puede ejecutarse de manera independiente.

```bash
git clone https://github.com/josecarlosonate/react-labs.git
cd react-labs/projects/nombre-del-proyecto
npm install
npm run dev
```

> Requiere Node.js y npm. Los comandos pueden variar según la configuración de cada aplicación.
